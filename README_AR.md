# NOVA Desktop الإصدار 3.0

أداة كمبيوتر سطح مكتب خفيفة وآمنة لنظام ويندوز، لمراقبة النظام، وتنظيف الملفات المؤقتة والكاش،
وإدارة اختصارات البرامج، ومراقبة سرعة الشبكة، والملاحظات المحلية، وإدارة ذاكرة الـ RAM، وإدارة DNS.

مبني بلغة بايثون وواجهة Tkinter. مصمم لنظام ويندوز 10 وويندوز 11 (64 بت).

المطور: مهران جمال

## المميزات

### نظرة عامة
- ملخص سريع لاستخدام المعالج والذاكرة وقرص النظام.
- نصائح مهمة حول إدارة الذاكرة والكاش في ويندوز.

### مراقبة النظام
- عرض فوري لاستخدام المعالج والذاكرة والقرص.
- قراءة درجة حرارة المعالج (عبر ACPI، عندما يتاحها ويندوز أو الجهاز).
- ملاحظة: قد لا تتوفر درجة الحرارة على جميع الأجهزة؛ NOVA لا يتحكم في المراوح.

### منظف الملفات والكاش
- يفحص مجلدات مؤقتة آمنة قبل الحذف:
  - ملفات المستخدم المؤقتة
  - كاش شادرات DirectX
  - كاش الصور المصغرة
  - ملفات Temp في ويندوز (الملاحظ المتاح فقط)
- يعرض الحجم وعدد الملفات قبل الحذف.
- يتطلب تأكيدًا قبل الحذف.
- يتخطي الملفات قيد الاستخدام أو المحمية.
- لا يمس مجلدات التنزيلات أو المستندات أو كلمات المرور أو بيانات تسجيل الدخول.

### مدير الذاكرة RAM (جديد في الإصدار 3.0)
- يعرض إجمالي الذاكرة المستخدمة والمتاحة.
- يعرض نسبة استخدام الذاكرة مع شريط تقدم.
- يعرض الذاكرة المخزنة مؤقتًا (الاستعداد) عندما تتوفر بيانات ويندوز.
- يعرض أكثر العمليات استهلاكًا للذاكرة.
- ترتيب العمليات حسب الاسم أو معرف العملية أو استهلاك الذاكرة.
- زر تحديث يدوي وخيار تحديث تلقائي.
- قسم توضيحي حول إدارة الذاكرة في ويندوز.
- **لا** ينهي عمليات النظام أو العمليات الحرجة تلقائيًا.
- **لا** يجبر مسح قائمة الاستعداد في ويندوز.

### مدير DNS (جديد في الإصدار 3.0)
- **مسح كاش DNS**: ينفذ أمر ipconfig /flushdns مع تأكيد ويعرض النتيجة.
- **إعادة تعيين إعدادات DNS**: يكتشف موصلات الشبكة، ويعرض خوادم DNS الحالية،
  ويعيد DNS إلى التلقائي (DHCP) لموصل محدد فقط (يتطلب تأكيدًا).
- لا يغير عناوين IP، ولا إعدادات الوكيل، ولا المجموعة الكاملة للشبكة.
- لا يجري أي تغييرات تلقائيًا عند تشغيل البرنامج.

### البرامج (اختصارات قائمة ابدأ)
- يعرض اختصارات قائمة ابدأ من مجلدات المستخدم وبرنامج البيانات.
- تشغيل الاختصار المحدد.
- يفتح إعدادات التطبيقات في ويندوز.

### مراقبة الشبكة
- معدل الإرسال والاستقبال الفوري (نشاط الواجهة المحلية، ليس اختبار سرعة الإنترنت).
- التحديث كل ثانية.

### الملاحظات
- ملاحظات سريعة تُحفظ محليًا في `%APPDATA%\NOVA Desktop\notes.json`.
- ملاحظاتك تُحفظ عبر الإصدارات.

## التثبيت

1. حمّل أو استنسخ هذا المستودع.
2. استخرج الملفات أو افتح المجلد.
3. انقر نقرًا مزدوجًا على `run_nova.bat`.
4. تتحقق الأداة من تثبيت بايثون، وتثبيت التبعيات، وتبدأ التطبيق.

### التثبيت اليدوي

```bash
py -m pip install -r requirements.txt
py nova_desktop.py
```

---

## الاستخدام

- запустите التطبيق باستخدام `run_nova.bat`.
-.navigate بين الصفحات باستخدام الشريط الجانبي الأيسر.
- مدير الذاكرة: عرض إحصائيات الذاكرة، تحديث، فرز العمليات.
- مدير DNS: مسح كاش DNS أو إعادة تعيين موصل محدد إلى DHCP (يتطلب تأكيدًا).
- المنظف: فحص وحذف الملفات المؤقتة المحددة.
- الملاحظات: كتابة وحفظ الملاحظات المحلية.

## ملاحظات السلامة

- لا ينهي NOVA عمليات النظام أو العمليات الحرجة تلقائيًا.
- لا يجبر NOVA مسح قائمة الاستعداد في ويندوز.
- تغييرات DNS تتطلب تأكيدًا صريحًا وتؤثر على الموصل المحدد فقط.
- عناوين IP لا تتغير أبدًا؛ فقط عناوين خوادم DNS تُعاد إلى التلقائي.
- المنظف يتخطي الملفات قيد الاستخدام أو المحمية.
- لا تجري أي إجراءات مدمرة تلقائيًا عند التشغيل.
