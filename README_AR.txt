NOVA Desktop 2.0
=================

التشغيل:
1) ثبّت Python 3.10 أو أحدث.
2) فك ضغط الملف.
3) افتح المجلد واضغط مرتين على run_nova.bat.
4) يحتاج اتصال إنترنت أول مرة لتثبيت psutil.

المميزات:
- لوحة عامة ومراقبة CPU / RAM / Disk.
- قراءة درجة حرارة ACPI إن كان Windows والجهاز يتيحانها. قد لا تظهر حرارة CPU/GPU الدقيقة على كل الأجهزة.
- تنظيف مجلد المستخدم المؤقت، كاش DirectX، ملفات الصور المصغرة، وملفات Windows Temp التي يمكن الوصول إليها.
- يعرض حجم الملفات قبل الحذف ويطلب تأكيدًا؛ الملفات المستخدمة أو المحمية يتم تخطيها.
- إدارة اختصارات قائمة Start وفتح إعدادات التطبيقات.
- مراقبة معدلات إرسال واستقبال الشبكة.
- ملاحظات محفوظة محليًا في %APPDATA%\NOVA Desktop.

مهم بخصوص RAM:
ويندوز يدير الذاكرة تلقائيًا. لا ينفذ NOVA مسحًا قسريًا للذاكرة أو إيقاف خدمات النظام؛
بدلًا من ذلك يعرض أكثر العمليات استهلاكًا ويفتح Task Manager لتغلق البرامج التي تعرفها بنفسك.
هذا أكثر أمانًا من أدوات "تنظيف الرام" التي قد تسبب بطئًا أو مشاكل.

ملاحظات الأمان:
- لا يحذف NOVA مجلد Downloads أو Documents أو ملفات البرامج.
- لا يحذف كاش المتصفحات أو بيانات تسجيل الدخول.
- راجع العناصر المحددة قبل الضغط على حذف.
- لا يتم التحكم في المراوح أو تغيير إعدادات الطاقة.
